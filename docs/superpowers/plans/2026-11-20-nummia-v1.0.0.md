# Nummia v1.0.0 — Plan de implementación

> **Para agentes:** SUB-SKILL REQUERIDA: superpowers:executing-plans (ejecución en esta sesión). Los pasos usan casillas (`- [ ]`).

**Objetivo:** primera versión instalable de Nummia. Incluye gastos, ingresos, reembolsos, «me lo devuelven», sueldo previsto, Inicio, Movimientos, detalle y formularios, apariencia (temas, 12 acentos, icono), modo discreto, copia local, actualizador y publicación automática en GitHub Releases.

**Arquitectura:** Android nativo con un solo módulo `app`, organizado en paquetes `ui` → `domain` → `data`. `domain` es Kotlin puro (cálculos en céntimos, probados exhaustivamente). `data` usa Room sobre SQLCipher y DataStore. La interfaz es Compose con Material 3, con estado inmutable expuesto en `StateFlow`.

**Stack:**
- Kotlin 2.1.0, AGP 8.7.3, Gradle 8.14.3 (wrapper).
- Compose BOM 2024.12.01, Material 3.
- Hilt 2.53.1, KSP 2.1.0-1.0.29.
- Room 2.6.1, `net.zetetic:sqlcipher-android:4.6.1`.
- DataStore 1.1.1, WorkManager 2.10.0, OkHttp 4.12.0, kotlinx-serialization 1.7.3.
- Pruebas: JUnit 4, Robolectric 4.14.1, Turbine 1.2.0.

**Especificación:** `docs/superpowers/specs/2026-11-20-nummia-design.md`

## Restricciones globales

- **Paquete:** `io.github.alexcorrea2001lemon.nummia`. `minSdk 26`, `compileSdk 35`, `targetSdk 35`, solo `arm64-v8a` en release.
- **Dinero:** `Long` en céntimos en todas las capas. Formato `1.520,75 €` (`es-ES`, cifras tabulares, signo `−` U+2212 para negativos en pantalla).
- **Versión:** `versionName "1.0.0"`, `versionCode 10000` (MAYOR×10000 + MENOR×100 + CORRECCIÓN).
- **Repositorio público:** el keystore y sus contraseñas solo llegan como secretos de GitHub (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`). Nunca hay datos reales en las pruebas.
- **Textos de la interfaz:** en español.
- **Pilares** (animación, batería, datos, diseño): ver `CLAUDE.md`. El APK release debe pesar menos de 10 MB.
- **Ideas descartadas** (no implementar): ver `CLAUDE.md`.
- **Reembolsos:** cuentan en el **mes del gasto**, nunca en el de su propia fecha.
- **Solo cuenta lo `CONFIRMADO` y no borrado.**

## Puntos de atención en la revisión

1. **Importes escritos a mano:** `"2,7"`, `"2,70"`, `"1.520,75"`, `"0,005"`, `""`, `"abc"`, `"-5"`. Cada uno se convierte bien o se rechaza con un mensaje claro, nunca se trunca sin avisar. → Tarea 2.
2. **Reembolsos con varios pagos y más altos que el precio:** el gasto real puede ser negativo y «falta por recuperar» nunca baja de 0. → Tarea 3.
3. **Mes sin ingresos:** el % de ahorro se muestra como «—», sin dividir entre cero. Un mes vacío muestra un estado vacío, no ceros con aspecto de error. → Tareas 3 y 7.
4. **Borrar y deshacer:** al deshacer, el gasto vuelve con sus reembolsos y su historial intactos, y los totales vuelven al céntimo. → Tarea 5.
5. **Actualizador:** si falla el SHA-256 o la firma, no se instala y el APK se borra. Si GitHub no responde o no hay red, no hay error visible, solo «No se pudo comprobar». → Tarea 12.

### Tarea 12: Actualizador

**Archivos:** `data/actualizar/*`, `ui/ajustes/ActualizarScreen.kt`, prueba `ActualizadorTest.kt` (MockWebServer).

**Produce:**
- `fun esMasNueva(tag: String, actual: String): Boolean`
- `suspend fun comprobar(): EstadoActualizacion`
- `suspend fun descargarYVerificar(rel): Result<File>`
- `fun instalar(file)`

Flujo:
1. Consulta `api.github.com/repos/alexcorrea2001-Lemon/Nummia/releases/latest`.
2. Busca el recurso `nummia-vX.Y.Z.apk` y su `.sha256`.
3. Descarga en `cacheDir/updates/`.
4. Comprueba el SHA-256 y la firma, con `PackageManager.getPackageArchiveInfo` + `GET_SIGNING_CERTIFICATES`.
5. Instala con `PackageInstaller` y `setRequireUserAction(USER_ACTION_NOT_REQUIRED)` en API 31 o superior.
6. Borra el APK en cualquier resultado y al arrancar.

Trabajo diario con WorkManager (red y batería no baja). Descarga solo con Wi-Fi por defecto.

- [ ] Pruebas:
  - `esMasNueva("v1.0.1", "1.0.0")` → true; `("v1.0.0", "1.0.0")` → false; `("v1.10.0", "1.9.0")` → true.
  - Un SHA distinto → error, y el archivo no existe al terminar.
  - Error HTTP 500 o sin red → `NoSePudoComprobar`.
- [ ] Commit.
